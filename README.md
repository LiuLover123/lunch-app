# 今天吃啥

每日午饭签到 PWA。零成本、零后端、零 API Key、可离线使用。

## 功能

- **每日签到**：点「今日签到」按规则生成当天推荐搭配（主食 + 主菜 + 素菜 各一）
- **搭配合理性**：纯规则引擎 —— 荤素搭配、分类齐全，并自动排除前后 2 天出现过的菜
- **一天一次**：今天签过之后直接显示菜品，不会重复随机覆盖
- **日历视图**：已签到日期显示主菜名；未签到的过去日期显示灰点（缺勤）；未来日期不可点
- **历史回看**：点日历上已签到的日期，下方显示那天的菜谱与照片；点空白日期显示「这天没有记录」；今天未签到时显示「今天偷懒了没有吃饭」+ 签到按钮
- **跨天自动刷新**：切回前台或每分钟检测，到第二天自动切换
- **菜品管理**：右上角 ＋ 添加菜品（主食 / 主菜 / 素菜），可删除
- **照片**：每天可上传一张照片，存于本地（自动压缩至 1280px）
- **离线可用**：Service Worker 缓存全部资源，断网也能打开
- **App 观感**：真全屏（无状态栏色差）、iOS 启动画面、禁用下拉回弹与双指缩放、App 风格标题栏

## 技术栈

纯静态 HTML / CSS / JS，无构建步骤、无依赖、无后端。

- 数据存储：IndexedDB（菜品 / 签到记录 / 照片）
- 搭配算法：`js/rules.js`（纯函数，可单测）
- 离线：`sw.js`（Cache Storage）
- 可安装：`manifest.json`

## 本地运行

必须通过 HTTP 服务访问（Service Worker 要求），直接双击 `index.html` 不行：

```bash
cd 今天吃啥
python3 -m http.server 8123
```

然后打开 http://localhost:8123

## 部署到 iPhone（零成本）

1. 把整个目录推到 GitHub 仓库
2. 仓库 Settings → Pages → 选分支保存，得到 `https://用户名.github.io/仓库名/`
3. iPhone Safari 打开该地址 → 分享 → 「添加到主屏幕」

之后它会像 App 一样全屏运行（无地址栏、有启动画面），且断网可用。

**分享给朋友**：把同一个链接发给他们，各自「添加到主屏幕」即可。每个人的数据都只存在自己手机里，互不可见。

> 注意：上架 App Store / 使用 TestFlight 需要 Apple Developer Program（¥688/年）。本项目走 PWA 路线，**不需要付费账号、不需要备案**。

## 数据说明

数据**只存在这台设备的浏览器里**。清除 Safari 数据、删除主屏图标、或 iOS 回收存储时，记录和照片会丢失，且无法恢复。

## 文件结构

```
index.html          页面结构
manifest.json       PWA 清单
sw.js               Service Worker（离线缓存）
css/style.css       样式（暖橙主题）
js/db.js            IndexedDB 数据层
js/rules.js         搭配规则引擎
js/app.js           界面逻辑
icons/              App 图标 + iOS 启动画面
```
